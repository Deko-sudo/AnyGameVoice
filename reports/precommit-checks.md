# Проверки перед коммитом

База — `834834e` с двумя локальными патчами, описанными в [patches.md](patches.md).

## 1. Импорты в main.py

`import json` и `from pathlib import Path` уже находились в начале `app/main.py` (строки 6 и 8). Интеграционный тест прошёл через запись и последующее чтение `report.json`.

## 2. Минимальная версия Python

В `pyproject.toml`, строка 11, указано `requires-python = ">=3.10"`. Файл `setup.py` делегирует настройку сборки этому конфигу. Файлы `setup.cfg` и `runtime.txt` в корне отсутствуют. Сигнатура `list[Line | Dialogue | ExtractedLine]` соответствует объявленному минимуму. Сохранены и сигнатура, и требование к версии.

## 3. Статус partial в UI

Исходный `doJob()` в `ui/index.html` выводил весь ответ через `JSON.stringify`. При частичном успехе в JSON было видно `"status": "partial"`. Пользователю приходилось самому соотносить счётчики и искать ошибки в массиве реплик. Теперь существующий блок статуса выводит отдельный заголовок, обе доли и причины. [Проверка отображения](ui-partial.md)
