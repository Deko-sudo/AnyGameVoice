## 2. Что осталось

Все четыре блока закрыты. Сохранены два согласованных ограничения. При переводе в выбранный язык ручной вариант требует заполненного совпадающего `target_lang`. Для реплики с `voice_id` используется голос персонажа. Тайм-аут очереди завершает ожидание задания, а зависший вызов модели может продолжать занимать поток.

## 4. Результаты тестов

Полный прогон на Python 3.14.8 и pytest 9.2.0 выполнялся в bubblewrap. Исходники, тесты и UI смонтированы только для чтения. Для записи использовались приватный `/tmp` и `reports/`. В сетевом пространстве был только loopback. Внешние API и модели не использовались.

```sh
python -B -m pytest -q -p no:cacheprovider tests
```

**68 passed, 1 warning in 1.32s.** Starlette предупредил об устаревающей поддержке установленного httpx в TestClient. HTTP-тест прошёл. Буквальная команда из задания с `-p no-cacheprovider` завершилась до сбора тестов с кодом 4 из-за поиска плагина с таким именем. Для отключения кэша pytest принимает форму `-p no:cacheprovider`.

Оба теста тайм-аута дополнительно прошли пять раз подряд. При контрольном вызове `cmd_mod` с обычным лимитом и `sleep(999)` одна реплика успела, вторая зависла, третья осталась в очереди. Через 60,034 секунды на диске были отчёт `partial`, один итоговый WAV и две причины `TTS timed out`. Обработчик страницы отдельно проверен в Node.js на ответах `running`, `done`, `partial` и `failed`.
