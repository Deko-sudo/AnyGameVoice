# Фаза 1. Установка и снятие мода по манифесту

**Фаза 1 готова.** CLI устанавливает набор файлов и сохраняет манифест. Проверки подтвердили откат при сбое установки, восстановление неизменённых файлов и сохранение пользовательских изменений при конфликте.

## Формат манифеста

Ниже пример для одной замены. Идентификатор содержит UTC timestamp в компактном формате ISO 8601 и шесть случайных шестнадцатеричных символов. Даты в полях JSON записываются в ISO 8601 UTC. Поля `original`, `backup` и `replaced_with` отсчитываются от директории игры, директории резервных копий и директории сгенерированных файлов соответственно.

```json
{
  "install_id": "20261123T095400.123456Z-a1b2c3",
  "created_at": "2026-11-23T09:54:00.123456+00:00",
  "game_root": "/x/y/game",
  "output_dir": "/x/y/output",
  "entries": [
    {
      "original": "voice/маяк.wav",
      "backup": "0000.bak",
      "replaced_with": "0.wav",
      "sha256_original": "15b12239dd66f813134d0d466832754be262ed2514b147af8a1f87b9f9c1a4bc",
      "sha256_replaced": "1fdc8bd632b2313a00cf6200afaf488d482e68b3173c031d2899c36c6c8d025b",
      "installed_at": "2026-11-23T09:54:00.125000+00:00",
      "uninstalled_at": null,
      "status": "installed"
    }
  ]
}
```

Для `game_root=/x/y/game` манифест размещается в `/x/y/.agv-manifests/<install_id>.json`, а копии в `/x/y/.agv-backups/<install_id>/`. Директория копий создаётся с режимом `0o700`. Рабочие пути проверяются на принадлежность своим каталогам после разрешения симлинков. Дубликаты целей отклоняются до замены файлов.

## Установка, конфликты и восстановление

- Установка проверяет все пары, сохраняет бэкап и SHA-256 перед заменой каждого файла. Запись WAV и манифеста публикуется через атомарное переименование на той же файловой системе. При ошибке копирования или записи манифеста уже применённые замены откатываются. Если сам откат завершился ошибкой, команда сообщает путь к сохранённым копиям.
- При снятии SHA-256 текущего WAV сравнивается с `sha256_replaced`. Изменённый файл получает `conflict`, его содержимое и доступная копия сохраняются. Отсутствующий целевой файл или бэкап дают `missing`. Статус `missing` добавлен к перечню допустимых статусов, чтобы сохранить это состояние между вызовами. Повторная команда снова перечисляет нерешённые записи. Остальные файлы восстанавливаются независимо.
- Перед восстановлением проверяется SHA-256 копии. Повреждённый бэкап даёт запись в `errors`, а WAV остаётся на месте. Если манифест после восстановления записать не удалось, предыдущая версия WAV возвращается на место и копия остаётся доступной для повтора.
- После успешного восстановления и записи статуса `uninstalled` использованная копия удаляется. Пустой каталог установки удаляется, когда все записи восстановлены. Для конфликтов и отсутствующих файлов каталог сохраняется. Неудачная очистка после успешного снятия отражается предупреждением.
- Манифест сохраняется после успеха для проверки истории и идемпотентности. Повтор команды возвращает количество ранее восстановленных записей в `already_uninstalled`. CLI выдаёт JSON и завершает работу с кодом 1 при конфликтах, пропусках или ошибках восстановления.

Атомарность относится к публикации отдельного файла и манифеста. Для обычных ошибок во время установки предусмотрен откат всего набора. Принудительное завершение процесса или сбой питания между заменами может потребовать ручного разбора копий и удаления оставшейся блокировки `.agv-manifests/.<game-name>.lock` после завершения процесса.

## Проверка

В `tests/test_manifest.py` добавлено 15 тестовых случаев.

| Проверка | Что подтверждено |
|---|---|
| Установка трёх файлов | Манифест, Unicode, права каталога, три копии, оба SHA-256, одинаковые имена файлов в разных каталогах. |
| Снятие и повторный вызов | Три побайтно восстановленных файла, три сохранённых статуса, удалённый пустой каталог и `already_uninstalled=3`. |
| Конфликт и отсутствующая копия | Два исправных файла восстановлены, проблемная запись сохранена, изменённый WAV остался на месте. |
| Проверка входных данных | Отсутствующий оригинал, симлинк за пределы игры, абсолютный путь в записи, обход через `..`, неверный хеш и неизвестный статус. |
| Ошибки операций | Откат первых двух файлов при частичной записи третьего, безопасный повтор после ошибки записи манифеста и отказ от испорченного бэкапа. |
| CLI | Установка через повторяющийся `--map`, JSON-отчёт, exit 1 при конфликте и exit 0 при чистом снятии. |

`python -B -m pytest -q -p no:cacheprovider tests` — **98 passed, 1 warning**. Предупреждение относится к существующему HTTP-тесту Starlette и httpx. Прогон выполнен с исходниками только для чтения, приватным `/tmp` и изолированной сетью. Собранный wheel содержит точки входа `agv` и `anygamevoice`.
