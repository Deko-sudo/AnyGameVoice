# Privacy Policy

## Our Philosophy

**We collect nothing. We track nothing. We send nothing.**

AnyGameVoice is a local-first application. All processing happens on your device.

## What We Scan (With Your Permission)

When you first launch the app, we ask permission to scan your hardware:

| Data | Purpose | Stored Where |
|------|---------|-------------|
| GPU model & VRAM | Recommend TTS model | Local config file |
| RAM amount | Determine batch size | Local config file |
| CPU cores | Parallel processing settings | Local config file |
| Free disk space | Model download warnings | Local config file |
| OS version | Compatibility check | Local config file |

**You can decline this scan** and configure settings manually.

## What We NEVER Collect

- IP address
- MAC address
- Personal files
- Browser history
- Game save data
- Usage analytics
- Telemetry of any kind

## API Keys

If you connect AI providers (OpenAI, Anthropic, etc.):

- Keys are stored **locally** in encrypted format
- Keys are **never** sent to our servers (we don't have servers)
- Keys are only used to communicate directly with the provider's API
- You can delete keys at any time in Settings

## Voice Samples

If you upload voice samples for cloning:

- Samples are stored **locally** on your device
- Samples are **never** uploaded anywhere
- You can delete samples at any time
- You are responsible for having rights to uploaded audio

## Third-Party Services

If you choose to use cloud TTS providers (ElevenLabs, OpenAI):

- Your text is sent to their API for processing
- We have no control over their data policies
- Review their privacy policies before use
- Local TTS models (XTTS, Piper) require no internet

## Your Rights

- View all collected data (Settings -> Privacy -> Show Data)
- Delete all scan data (Settings -> Privacy -> Delete Data)
- Export your project data
- Use the app completely offline (with local TTS models)

## Changes to This Policy

Any changes will be documented in CHANGELOG.md.
