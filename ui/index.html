Как пользоваться AnyGameVoice

Для начала достаточно выбрать установленную игру.

  1. Выберите игру

    Приложение найдёт доступные библиотеки Steam и стандартную папку игр. Нажмите «Выбрать из библиотеки» и выберите название. Или нажмите «Указать папку» и откройте каталог, где лежит файл запуска игры — например, SteamLibrary/steamapps/common/Название игры.

    Выбирайте саму игру, а не сохранения, рабочий стол или всю библиотеку. Если внутри несколько игр, приложение предложит выбрать одну.

  2. Выберите переводчик

    Для английских реплик студия предложит «English → Русский». В панели «Озвучка» выберите провайдера и модель перевода. Ollama работает на компьютере. Для облачного запроса студия попросит подтверждение. Автоматический режим подберёт установленный голос для русского текста.

    Если нужен исходный язык, выберите «Озвучить исходный текст».

  3. Послушайте до трёх реплик

    Нажмите «Пробный дубляж». В разделе «Генерация» сравните оригинал с переводом и послушайте голос. Если результат подходит, нажмите «Создать автоматически». Полный дубляж использует готовые записи с теми же настройками.

  4. Слушайте или запускайте игру

    Кнопка «Открыть папку результата» покажет WAV-файлы и отчёт. Реплики можно прослушать в студии.

    В Ren’Py и Lost Coast мод устанавливается и проверяется автоматически: перезапустите игру. «Отключить озвучку» возвращает исходный звук после перезапуска игры. Голос, синхронизацию губ и поведение сцен нужно проверить в самой игре.

Что поддерживается сейчас

Lost Coast: русские субтитры → новый голос Рыбака → мод в lostcoast/custom. Кашель, шумы и реплики без надёжной связи со звуком сохраняются. Комментарии разработчиков не переозвучиваются. Оригинальные архивы не изменяются.

Ren’Py (.rpy): автоматическая установка и проверка мода по идентификаторам движка. Нужен Ren’Py SDK; установленный SDK определяется автоматически или выбирается через «Настроить вручную». Сценарий должен поддерживаться полностью. RPG Maker (Map JSON), Godot Dialogue Manager (.dialogue): автоматическое создание аудиофайлов. Подключение их в игру пока выполняется отдельно. Для Unity, Unreal, .rpa и .rpyc нужен соответствующий адаптер; приложение сообщит об этом до записи.

Если голос или компонент не найден

Нажмите «Подготовить приложение» в панели автоматического режима. Доступны русский и английский голоса, Piper, SDK Ren’Py (Linux x86-64/ARM64) и FFmpeg для Lost Coast. Приложение покажет размер, источник и лицензию, установит компоненты отдельно от системы и выполнит пробную запись. После подготовки прерванный автоматический запуск продолжится. Для других голосов укажите пару имя.onnx и имя.onnx.json через «Настроить вручную» → «Основной голос».

Если папка не подходит

В Steam откройте игру → «Управление» → «Просмотреть локальные файлы». Эту папку нужно выбрать в AnyGameVoice. Для Lost Coast подходит также папка Half-Life 2: приложение найдёт lostcoast внутри. Для SDK выберите каталог с файлом renpy.sh.

Если нужны разные голоса

Выключите «Автоматически» до выбора игры. Откройте «Настроить вручную», выберите язык и основной голос, затем назначьте другие голоса в разделе «Персонажи». Для Ren’Py и Lost Coast нажмите «Создать и подключить выбранный голос» — приложение проверит и установит мод с вашими голосами. Кнопка «Создать озвучку» сохраняет только аудиофайлы.

      Синтез речи
      Исследование игры

      Требования — предварительная оценка по свободной RAM, не гарантия запуска. Совместимость GPU и скорость нужно проверить отдельно. Ручной выбор голоса выключает автоматический режим, чтобы его не перезаписали.

      Другие модели для работы с голосом

      XTTS v2 использует образец голоса; требуется отдельно установить совместимый движок и проверить веса, затем назначить WAV персонажу. Однокнопочной установки XTTS пока нет.

      Qwen3-TTS Base · клонирование голоса — перспективная альтернатива; подключение в приложении и совместимость с этим ПК ещё не проверены.

      Whisper · распознавание речи — для превращения аудио в текст; в приложении пока не подключён. Это отдельная задача от синтеза голоса.
