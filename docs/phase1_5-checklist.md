# Phase 1.5 — ручная проверка на игре Ren’Py

Открой [шаблон отчёта](phase1_5-report-template.md) и заполняй его по ходу сеанса. Сохрани путь к манифесту сразу после установки.

## Pre-flight

- [ ] Запустить чистую копию игры в Ren’Py SDK. Убедиться, что открываются меню и диалог, а исходная озвучка слышна. Затем закрыть игру.
- [ ] Проверить, что в `game/*.rpy` есть хотя бы одна озвученная реплика с буквальным `voice "voice/имя.wav"` непосредственно перед ней. Выбрать сцену с меню и знать, как пройти обе ветки.
- [ ] Убедиться, что поверх этой копии игры нет другого мода.
- [ ] Выбрать новый или пустой каталог вывода вне игры. Подготовить Ollama или другой настроенный провайдер перевода. Для Piper указать путь к голосовой модели `.onnx`.

## Install

- [ ] Запустить из корня AnyGameVoice, подставив свои пути и язык.

  ```bash
  bash scripts/phase1_5_smoke.sh --game "/path/to/game" --output "/path/to/smoke-output" \
    --target es --engine piper --voice "/path/to/model.onnx"
  ```

- [ ] В `report.json` проверить `status=done` или `partial`. Для `partial` записать `failed/total` и причины из `lines[].skipped_reason`.
- [ ] Проверить, что `agv install` завершился. Записать путь из `phase1_5_state.json` и число реально установленных реплик из `entries` манифеста.
- [ ] В `phase1_5.log` отметить, какие сцены и реплики получат звук. Генерация и установка могут иметь разные числа реплик.

## Play-through

- [ ] Запустить игру в SDK после установки.
- [ ] Пройти обе ветки меню, при необходимости начав сцену заново.
- [ ] Проверить, что в каждой доступной ветке с установленными WAV звучат ожидаемые переведённые реплики. Зафиксировать ветку, если её записи не вошли в манифест.
- [ ] Сопоставить услышанное с `dialogue.srt` рядом с WAV. Текст диалогов внутри Ren’Py остаётся исходным, поскольку установка меняет звуковые файлы.
- [ ] Проверить, что нет сообщения `voice file not found`, визуальных сбоев или воспроизведения чужой реплики.
- [ ] Проверить, что игра не завершилась аварийно. Закрыть игру перед снятием.

## Uninstall

- [ ] Выполнить команду из лога с сохранённым путём манифеста.

  ```bash
  bash scripts/phase1_5_smoke.sh --uninstall "/path/to/.agv-manifests/install-id.json"
  ```

- [ ] Проверить `OK` и отчёт. При первом снятии `restored=N`, где `N` — число записей манифеста. `conflicts`, `missing` и `errors` должны быть пустыми.
- [ ] Проверить в логе сравнение SHA-256 восстановленных файлов по манифесту и всего обычного содержимого `game/voice/` по снимку до установки. Ожидание — ноль добавленных, удалённых или изменённых файлов.
- [ ] Запустить игру и прослушать 2–3 реплики. Оригинальная озвучка должна вернуться.

## Если что-то сломалось

- [ ] Сохранить `phase1_5.log`, `report.json`, `phase1_5_state.json` и файл манифеста. При конфликте или отсутствующей копии сохранить весь каталог резервных копий для разбора.
- [ ] Записать в отчёт шаг, действие, ожидаемый и фактический результат и приложить нужный отрывок лога.
